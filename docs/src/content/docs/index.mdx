## Usage

```ts
import { toEnglishWords, fromChineseWords, convertTo, anyToNumber } from 'convnum'

toEnglishWords(12345) // 'twelve thousand three hundred forty-five'
fromChineseWords('一万二千三百四十五') // 12345
convertTo(2024, { type: 'roman' }) // 'MMXXIV'
anyToNumber('vingt-et-un') // 21
```

## Supported Types

`NumType` is the union of every representation the library understands. See the
[API reference](/api/readme/) for the full list, and try them live in the
[Numeral Converter](/tools/numeral-conversion/) and
[Sequence Generator](/tools/sequence-generator/). Every one of them can also start a
range in [Range & Transform](/range-transform/insert-sequence/).

| Name | `NumType` | Examples |
| --- | --- | --- |
| Decimal | `decimal` (alias `dec`) | `123`, `456` |
| Latin letters | `latin_letter` | `A`, `b`, `Z` |
| Month | `month_name` | `January`, `JAN`, `février` |
| Day of week | `day_of_week` | `Monday`, `MON`, `mardi` |
| Roman numerals | `roman` | `VI`, `vi`, `MMMCMXCIX` |
| Eastern Arabic | `arabic` | `٠`, `١`, `٢` |
| English words | `english_words` | `one hundred twenty-three` |
| English ordinal words | `english_ordinal_words` | `first`, `twenty-first` |
| English ordinal abbr. | `english_ordinal_abbr` | `1st`, `2nd`, `3rd` |
| French words | `french_words` | `cent-vingt-trois` |
| French ordinal words | `french_ordinal_words` | `premier`, `vingt-et-unième` |
| French ordinal abbr. | `french_ordinal_abbr` | `1er`, `1re`, `2e` |
| Chinese words | `chinese_words` | `一万三千零二`, `一萬三千零二` |
| Chinese financial | `chinese_financial` | `壹万叁仟零贰` |
| Binary | `binary` (alias `bin`) | `1010`, `0b1101` |
| Octal | `octal` (alias `oct`) | `777`, `0o456` |
| Hexadecimal | `hexadecimal` (alias `hex`) | `1A`, `0xFF` |
| Greek letters | `greek_letter` | `Α`, `α`, `Ω` |
| Greek letter names | `greek_letter_english_name` | `Alpha`, `BETA` |
| Cyrillic letters | `cyrillic_letter` | `А`, `я` |
| Hebrew letters | `hebrew_letter` | `א`, `ת` |
| Chinese Heavenly Stems | `chinese_heavenly_stem` | `甲`, `乙` |
| Chinese Earthly Branches | `chinese_earthly_branch` | `子`, `丑` |
| Chinese Solar Terms | `chinese_solar_term` | `立春`, `惊蛰` |
| Astrological signs | `astrological_sign` | `Aries`, `Pisces` |
| NATO phonetic | `nato_phonetic` | `Alfa`, `Bravo` |
