## 用法

```ts
import { toEnglishWords, fromChineseWords, convertTo, anyToNumber } from 'convnum'

toEnglishWords(12345) // 'twelve thousand three hundred forty-five'
fromChineseWords('一万二千三百四十五') // 12345
convertTo(2024, { type: 'roman' }) // 'MMXXIV'
anyToNumber('vingt-et-un') // 21
```

## 支持的类型

`NumType` 汇总了库支持的所有表示形式。完整列表见[API 参考](/convnum/api/readme/)；也可以在[数字转换器](/convnum/zh-cn/tools/numeral-conversion/)和[序列生成器](/convnum/zh-cn/tools/sequence-generator/)中试用。每一种类型都可以作为 [Range & Transform](https://toolsu.com/range-transform/zh-cn/insert-sequence/) 中范围的起点。

| 名称 | `NumType` | 示例 |
| --- | --- | --- |
| 十进制 | `decimal`（别名 `dec`） | `123`, `456` |
| 拉丁字母 | `latin_letter` | `A`, `b`, `Z` |
| 月份 | `month_name` | `January`, `JAN`, `février` |
| 星期 | `day_of_week` | `Monday`, `MON`, `mardi` |
| 罗马数字 | `roman` | `VI`, `vi`, `MMMCMXCIX` |
| 东阿拉伯数字 | `arabic` | `٠`, `١`, `٢` |
| 英语数字词 | `english_words` | `one hundred twenty-three` |
| 英语序数词 | `english_ordinal_words` | `first`, `twenty-first` |
| 英语序数词缩写 | `english_ordinal_abbr` | `1st`, `2nd`, `3rd` |
| 法语数字词 | `french_words` | `cent-vingt-trois` |
| 法语序数词 | `french_ordinal_words` | `premier`, `vingt-et-unième` |
| 法语序数词缩写 | `french_ordinal_abbr` | `1er`, `1re`, `2e` |
| 中文数字 | `chinese_words` | `一万三千零二`, `一萬三千零二` |
| 中文大写数字 | `chinese_financial` | `壹万叁仟零贰` |
| 二进制 | `binary`（别名 `bin`） | `1010`, `0b1101` |
| 八进制 | `octal`（别名 `oct`） | `777`, `0o456` |
| 十六进制 | `hexadecimal`（别名 `hex`） | `1A`, `0xFF` |
| 希腊字母 | `greek_letter` | `Α`, `α`, `Ω` |
| 希腊字母英文名称 | `greek_letter_english_name` | `Alpha`, `BETA` |
| 西里尔字母 | `cyrillic_letter` | `А`, `я` |
| 希伯来字母 | `hebrew_letter` | `א`, `ת` |
| 天干 | `chinese_heavenly_stem` | `甲`, `乙` |
| 地支 | `chinese_earthly_branch` | `子`, `丑` |
| 二十四节气 | `chinese_solar_term` | `立春`, `惊蛰` |
| 星座 | `astrological_sign` | `Aries`, `Pisces` |
| 北约音标 | `nato_phonetic` | `Alfa`, `Bravo` |
